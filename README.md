# PawTrust 爪印识途

原生 iOS 地图原型。用 SwiftUI 和 MapKit 画全屏可交互地图，在上面放搜索、筛选、爪印标记和可拖动的详情抽屉。第一版面向养狗的人，覆盖日常遛狗和周末出行，基础地点先放上海和深圳的遛狗地、餐饮候选和商场。

数据怎么流动、什么能留在本机、什么不能留，写在 [Docs/数据流与隐私边界.md](Docs/数据流与隐私边界.md)。那份说明不是安全认证。

原先仓库只有一行占位标题，没有源码。这个工程是第一份实现。

## 环境

- 最低系统 **iOS 17.0**。地图用的是 SwiftUI `Map`、`Annotation`、`MapCameraPosition` 和 `MapStyle`，这些 API 从 iOS 17 开始能完整自定义标记。
- 用 **Xcode 16 或更新版本**打开 `PawTrust.xcodeproj`。工程使用 Xcode 16 的同步目录格式。
- 依赖只有本地 Swift 包 `Packages/PawTrustCore`。没有 CocoaPods，也没有远程库。底图、抽屉和配色只借用了「浅色地图、多段抽屉、中性灰阶」这几条原则。

## 在 Mac 上运行

1. 安装 Xcode 16 或更新版本，并安装 **iOS 17 或更高**的模拟器。
2. 打开 `PawTrust.xcodeproj`。
3. 方案选 **PawTrust**，设备选一台 iPhone 模拟器。
4. 签名：
   - 模拟器：Signing & Capabilities 里 Team 可以留空。若 Xcode 仍要求签名，把 Debug 的 Code Signing Identity（Any iOS Simulator SDK）设为 **Sign to Run Locally**。
   - 真机：把 Signing 改为 Automatic，并选择你自己的 Team。Bundle ID 是 `com.pawtrust.demo.pawprints`，可以改成你的。
5. Run。首次启动停在上海中心一带，**不会**弹出定位权限。

逻辑测试不依赖模拟器：

```bash
cd Packages/PawTrustCore
swift test
```

Xcode 自带的 `swift` 就可以跑这个包。

## 狗证门槛

Release 构建打开后先看到门槛，不进地图。可以在本机识别证件或自己填写犬只档案。识别使用设备上的 Apple Vision，只提取犬名、品种、性别、年龄段和体型。主人姓名、住址、电话、证件号、犬证号、芯片号、原图和完整识别文本不写入档案，也不上传。档案可以清除。清除不会删除相册里的原图。

当前没有合规的狗证验真服务。`UnavailableDogLicenseVerifier` 固定返回不可用，正式模式因此保持锁定。保存档案或识别到“犬证”都不是审核通过。

调试构建在已经保存档案之后，可以点“进入演示地图（不是审核通过）”。地图上会一直显示这句边界。Release 没有这个入口。

## 一句话检索和到访记录

搜索框接受“深圳 能带大狗进室内的餐厅”或“附近有围栏的遛狗地”。整理结果是可删除的城市、类别和条件标签，标注为本地解析，不是已连接的语言模型。未知条件单独列出，不算满足。没有确认时间的规则也不算满足。

可以添加地点或记下某一次观察。保存前能改字段。记录只在本机，状态是待审核且未同步，不会变成已确认规则。连续保存有本机间隔，这不是安全防护。

## 怎么操作

启动之后地图大约占屏幕七成以上，搜索和筛选浮在地图上。

- **搜索**：按公园名、区或类型过滤标记和底部数量。旁边的叉会清空搜索。
- **筛选**：全部、可放绳、有水源、有围栏。后三项可以叠加，地图上的爪印会跟着变。
- **附近**：这时才申请「使用期间」定位，并按真实距离重排。拒绝之后仍可浏览，距离保持「示意」。
- **定位按钮**：已有位置就移过去；还没问过就去申请；已经拒绝就回到上海示例区域。
- **爪印**：点一下选中，出现光圈、示例照片和地名，抽屉升到半屏。再点一次取消。
- **底部卡片**：点卡片打开当前建议地点。卡片下方的书签只看收藏，不删除收藏。
- **抽屉**：抓住顶部横条上下拖，停在收起、半屏、展开。收到最底会取消选择。VoiceOver 可在横条上上下轻扫。半屏里的「完整说明」和展开后的「收起」是同一组停靠。
- **收藏**：详情里的书签写入本机 `UserDefaults`，下次打开还在。
- **查看步行路线**：先出现说明。确认后才离开本应用，由 Apple 地图规划步行路线。应用里没有路线折线。

抽屉升起后，露出的地图区域仍然可以平移和缩放。地图保持朝北，不支持旋转，避免爪印标记跟着转。

## 公开地点和示例数据

| 内容 | 性质 |
| --- | --- |
| 复兴公园、襄阳公园、静安雕塑公园、人民公园、徐汇滨江绿地的名称和坐标 | 公开公园的近似位置，方便 Apple 地图显示，不是测绘边界 |
| 牵绳、围栏、水源、介绍文案 | 演示用，**未核实**，不是许可、风险或法律结论 |
| 未点「附近」、或还没有位置时的距离 | 示例数字，界面写「示意约」 |
| 点「附近」并拿到位置之后的距离 | 按当前位置估算的直线距离，不是步行路线长度 |
| 气泡和详情里的照片 | 打包在应用里的示例照片，不是这些公园的实拍，也不是实时画面。资源缺失时改为本地绘制的占位 |
| 步行路线 | 只交给 Apple 地图。本应用不导航 |

地图角落的说明是：「真实地点位置 · 携犬规则未核实」。详情里的准入规则单独列出，未知不会被说成已经满足。商场会写明整体信息不等于每一家店。

## 相对确认稿的修正

确认稿里的版式保留了：暖白卡片、细边和阴影、钴蓝、全屏地图、悬浮搜索、筛选条、小爪印、选中光圈、照片气泡、底部附近卡，以及带照片的详情抽屉。

这几处按可交互的真实地图改过了：

- 「溪岸公园」改为真实的 **徐汇滨江绿地**。底图街道由 Apple 地图绘制。
- 没有文字的水滴筛选改为 **有围栏**。
- 水源用 `drop.fill`。牵绳、围栏、水源都配文字。
- 搜索栏右侧不再放一个像账号头像的圆图，改为爪印符号。这个原型没有登录。
- 距离在未定位时带「示意」。路线按钮写明交给 Apple 地图。

## 本环境实际跑过什么

编写和检查发生在 Ubuntu 24.04 上。系统里没有 `xcodebuild`，也没有 iOS 模拟器，所以 **没有编译 PawTrust.app，没有启动模拟器，也没有 iPhone 运行截图**。

为了跑纯逻辑测试，使用 Swift 6.2.1（Linux）。在 `Packages/PawTrustCore` 执行 `swift test`：**23 个测试通过，0 失败**。其中 `CatalogTests` 4 个，`ExploreLogicTests` 10 个，`PrivacyAndAccessTests` 9 个。后者覆盖白名单提取、审核状态机、未知规则、本地解析、贡献节流、调试截图参数本身不会解锁地图，以及源码里的存储和外发路径扫描。界面测试 `PawTrustUITests` 需要 Mac 上的模拟器，这里没有跑。

这些测试不包含 SwiftUI、MapKit 或 Vision。它们通过，只说明这些计算和源码扫描是对的，不能当成应用已在 iOS 上打开，也不能当成物理零残留的证明。

另外检查了 `project.pbxproj` 的括号平衡，以及工程对象 ID 都有定义。这不是编译。

## 调试截图

只对 **Debug** 构建生效。Release 会忽略 `-PawTrustDemoScreenshots`，也不会因此打开地图。截图使用合成犬只「豆豆 / 贵宾 / 母 / 小型 / 成年」，写在单独的临时存储里，并在画面上标明「调试截图 · 合成示例 · 不是真实证件 · 不是审核通过」。

手动启动时，在模拟器安装 Debug 包后：

```bash
xcrun simctl launch 92F16493-876C-4CBB-AE77-1F779BCEF097 com.pawtrust.demo.pawprints -PawTrustDemoScreenshots gate
xcrun simctl launch 92F16493-876C-4CBB-AE77-1F779BCEF097 com.pawtrust.demo.pawprints -PawTrustDemoScreenshots map
xcrun simctl launch 92F16493-876C-4CBB-AE77-1F779BCEF097 com.pawtrust.demo.pawprints -PawTrustDemoScreenshots detail
xcrun simctl launch 92F16493-876C-4CBB-AE77-1F779BCEF097 com.pawtrust.demo.pawprints -PawTrustDemoScreenshots profile
```

第二个参数分别是门槛、演示地图、徐汇滨江绿地详情、合成档案。每次启动前可以先 `simctl terminate`。

界面测试 `PawTrustUITests` 用同样的参数截四张图，附在 xcresult 里。若设置了 `PAWTRUST_SCREENSHOT_DIR`，测试进程还会在该目录写 PNG。这台仓库所在的 Linux 环境没有执行过这些命令。

## 请在 Mac 上核对

1. `swift test` 通过，并且 Xcode 能在 iPhone 模拟器里 Run。
2. Release 构建停在门槛页，请求核验后地图仍然锁定，并说明服务没有接入。调试构建先保存档案，再点“进入演示地图（不是审核通过）”，横幅保持这句边界。
3. 演示地图默认在上海。搜索「滨江」能看到徐汇滨江绿地。说“深圳 能带大狗进室内的餐厅”后，结果落在条件未知，而不是已确认符合。
4. 「可放绳」只剩襄阳公园；再点「全部」恢复。
5. 点爪印出现光圈、照片气泡和半屏详情；再点同一爪印，或下拉到收起，或点照片上的关闭，选择取消。
6. 拖动横条能停在三档。半屏和展开时，露出的地图仍能平移。
7. 收藏后详情书签变实心，底部书签只显示已收藏的地点。杀掉进程再打开，收藏还在；「仅看收藏」会回到关闭。
8. 详情写着规则未核实。未定位时距离带「示意」。
9. 点「附近」才出现系统定位说明。模拟器要在 Features → Location 里选一个位置，否则可能拿不到坐标。拒绝定位后仍可浏览。
10. 「查看步行路线」先出现说明，确认后才打开 Apple 地图。应用内没有路线线。
11. 把动态字体调到很大，按钮高度仍能点到，文字换行而不是被裁没。打开 VoiceOver，爪印、筛选和路线说明能被读出来。
12. Apple 地图标志在左下角可见。若被抽屉挡住，把 `ExploreScreen` 里 peek 的底部留白加大。

## 没有做的事

- 合规的狗证验真、审核后端，以及会返回“最少必要有效性结果”的正式签发方
- 语言模型或付费模型。一句话检索是本地关键词解析
- 业务后端、登录、支付、用户密钥，地点贡献的服务器同步
- 行程生成、天气检查、线上自动维护
- 应用内导航，或把示例路线画成可用路径
- 已确认的携犬许可。样本规则保持未知
- iPad 专属布局。目标设备是 iPhone，竖屏
