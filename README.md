# 爪印识途 (PawTrust) V2 — 全屏空间地图与流体动效版

> **声明**：本工程所有地点、信任分、预警及城市规则均为**演示数据、未核实、不能当法律依据**；高温提示不可替代兽医建议。

## V2 核心升级点（对标 Apple Maps 与 GitHub 流体设计案例）

1. **100% 全屏空间地图画布 ([index.html](./index.html))**：
   - 彻底移除首屏外围调试栏与冗余侧边栏，地图 `100vw × 100vh` 全屏铺底（右上角 `📱` 按钮可随时切换全屏或 iPhone 16 Pro 极简边框，`◐` 按钮可切换深色/浅色极简底图）。
2. **地图空间区域绘制（Polygon + Radius Circle + 胶囊锚点）**：
   - 直接在地图上绘制**绿色实线多边形（双门围栏放绳区）**、**琥珀色虚线多边形（外围共享必牵绳区 / 非公园市政绿化带走廊）**、**绯红色禁区多边形（普通公园禁狗红线对照区）**与**投毒高危脉冲半径圈**。
3. **色彩收敛与三级渐进式信息披露**：
   - 全局采用低饱和度石板灰毛玻璃，严格限制仅 **3 种语义信号色**（翠绿 `#10B981`、琥珀 `#F59E0B`、绯红 `#EF4444`）。
   - 对标 [Wouter125/BottomSheet](https://github.com/Wouter125/BottomSheet) 与 [nathangitter/fluid-interfaces](https://github.com/nathangitter/fluid-interfaces)，采用 `cubic-bezier(0.32, 0.72, 0, 1)` 弹簧阻尼三段位抽屉（`Peek` 露头 / `Half` 半屏 / `Full` 全屏）：列表态每张卡片严控在 **3 行以内**，点击卡片或地图区域后才平滑展开 Bento 二级详情与三态核实投票。
